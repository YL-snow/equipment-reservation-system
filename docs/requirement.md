# 需求说明

## 项目名称

实验室设备预约与耗材管理系统

## 项目简介

实验室设备预约与耗材管理系统是一个面向高校实验室的设备资源管理平台。系统提供设备预约、冲突检测、预约审核、耗材库存管理等功能。

主要业务流程：学生登录系统 → 浏览设备列表 → 选择设备提交预约 → 管理员审批 → 学生领用/归还 → 库存自动更新。

## 用户角色

| 角色 | 说明 |
|---|---|
| 管理员 (ADMIN) | 管理设备、审批预约、管理用户、查看所有预约记录 |
| 学生 (STUDENT) | 浏览设备、创建预约、查看个人预约记录 |

## 核心功能

| 功能 | 说明 |
|---|---|
| 设备浏览 | 展示设备列表，支持按分类筛选、按名称搜索 |
| 预约创建 | 选择设备和时间段，系统自动检测时间冲突 |
| 审批管理 | 管理员审批/驳回预约，确认设备归还 |
| 用户管理 | 用户注册登录、密码重置、角色管理 |
| 库存管理 | 预约扣减库存、归还恢复库存、记录变更流水 |

## 页面清单

| 页面 | 功能 | 访问权限 |
|---|---|---|
| 登录页 (/login) | 用户登录 | 公开 |
| 注册页 (/register) | 新用户注册 | 公开 |
| 设备列表页 (/) | 查看设备列表，按分类/名称筛选 | 登录用户 |
| 新建预约页 (/reservations/new) | 选择设备、时间段，提交预约 | 登录用户 |
| 预约记录页 (/reservations) | 查看个人/全部预约记录，按状态筛选 | 登录用户 |
| 审批管理页 (/approval) | 审批/驳回预约，归还确认 | 管理员 |
| 用户管理页 (/admin/users) | 查看用户、重置密码、修改角色 | 管理员 |

## 约束条件

- 前后端分离
- 本地启动
- 使用 MySQL 数据库持久化
- 至少 3 个页面（实际 7 个）
- 至少 5 个接口（实际 19 个）
- 至少 2 张表（实际 5 张表）
- JWT 认证
