# 需求说明

## 项目名称

实验室设备预约与耗材管理系统 (Equipment Reservation System)

## 项目简介

实验室设备预约与耗材管理系统是一个面向高校实验室的设备资源管理平台，旨在解决传统人工登记方式效率低、易出错、无法追溯的问题。系统提供设备浏览、预约创建、冲突检测、管理员审批、库存追踪等完整功能。

## 用户画像

### 人物 A：实验室管理员 — 张老师

> "每天都有学生来借设备，登记本写得很乱，谁借了什么、什么时候还全靠问，太累了。"

- 年龄：35-55 岁
- 背景：高校实验室管理人员，对计算机操作有一定了解
- 痛点：人工登记费时、设备去向不明、库存盘点困难、学生超期不还
- 期望：能看到谁借了什么、什么时候该还、库存还剩多少

### 人物 B：在校学生 — 小李

> "要做实验的时候经常发现设备被人借走了，也不知道谁在用、什么时候能还。"

- 年龄：18-25 岁
- 背景：理工科本科生/研究生，熟练使用手机和网页应用
- 痛点：不知道设备是否可用、预约靠跑腿找管理员、借用时间无法灵活安排
- 期望：能在线查看设备状态、提前预约、随时查看自己的借用记录

## 用户故事

### 优先级 P0 (必须有)

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-001 | 作为学生，我想要注册账号，以便使用系统 | 注册成功后可登录；学号唯一；密码需包含字母和数字 |
| US-002 | 作为学生，我想要登录系统，以便查看和预约设备 | 登录成功返回 JWT Token；Token 过期后需重新登录 |
| US-003 | 作为学生，我想要浏览设备列表，以便了解有哪些设备可用 | 展示设备名称、型号、可用数量、分类；支持按分类筛选和名称搜索 |
| US-004 | 作为学生，我想要预约设备，以便在特定时间段使用 | 选择设备、数量、时间段；系统自动检测冲突；提交后状态为待审批 |
| US-005 | 作为管理员，我想要审批预约，以便控制设备的使用 | 可通过/驳回预约；通过后扣减库存 |
| US-006 | 作为管理员，我想要确认设备归还，以便更新库存状态 | 归还后恢复可用数量；记录变更日志 |

### 优先级 P1 (应该有)

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-007 | 作为学生，我想要查看自己的预约记录，以便了解借用历史 | 按状态筛选；显示设备、时间、审批状态 |
| US-008 | 作为管理员，我想要管理用户，以便维护系统秩序 | 查看用户列表、重置密码、修改角色 |
| US-009 | 作为学生，我想要修改密码，以保障账号安全 | 需验证原密码；新密码需符合强度要求 |
| US-010 | 作为管理员，我想要查看所有预约记录，以便全面掌握设备使用情况 | 可查看全部预约，不受角色限制 |

### 优先级 P2 (可以有)

| ID | 用户故事 | 验收标准 |
|----|---------|---------|
| US-011 | 作为管理员，我想要浏览与筛选设备分类，以便更好地组织设备 | 分类列表查询与筛选（增删改接口预留） |
| US-012 | 作为系统，我希望在预约前进行冲突检测，避免双重预订 | 同一设备同时间段只能有一个通过或待审批的预约 |
| US-013 | 作为管理员，我想要将违规用户加入黑名单，以约束用户行为 | 黑名单用户无法提交新预约 |

## MoSCoW 优先级矩阵

| 分类 | 功能 | 理由 |
|------|------|------|
| **Must Have** | 用户注册/登录、设备浏览、预约创建、冲突检测、预约审批、设备归还 | 核心业务闭环，缺少任一环节系统无法运行 |
| **Should Have** | 预约记录查询、用户管理（重置密码/改角色/失信名单）、密码修改 | 提升使用体验和管理效率，不影响核心流程 |
| **Could Have** | 设备分类增删改、消息通知、数据统计报表、LDAP 集成 | 完善管理功能，可在 v1.1 迭代中交付（黑名单机制、库存变更流水已实现） |
| **Won't Have** | 消息通知、数据统计报表、LDAP 集成 | 超出当前范围，未来版本考虑 |

## 功能模块

### 模块一：认证与用户管理
- 注册（学号 + 密码 + 姓名）
- 登录（JWT 认证）
- 密码修改（原密码验证）
- 密码重置（管理员操作）
- 角色管理（ADMIN / STUDENT）
- 黑名单管理

### 模块二：设备管理
- 设备列表（分页 + 分类筛选 + 名称搜索）
- 设备详情（规格、库存、预约状态）
- 设备分类浏览与筛选（增删改接口预留）

### 模块三：预约管理
- 创建预约（设备 + 数量 + 时间段）
- 冲突检测（基于乐观锁）
- 预约审批（通过/驳回）
- 确认归还
- 预约记录查询（个人/全部）

### 模块四：库存管理
- 预约扣减库存
- 归还恢复库存
- 库存变更流水记录

## 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 页面加载 < 2s，接口响应 < 500ms |
| 安全 | 密码 BCrypt 加密存储；JWT Token 认证；SQL 注入防护 |
| 兼容性 | 支持 Chrome / Edge 最新版本 |
| 可用性 | 关键操作有确认提示和错误反馈 |
| 数据一致性 | 预约冲突检测使用乐观锁，防止超卖 |
