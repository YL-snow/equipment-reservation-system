# 指标与验收

## 1. 产品目标与北极星指标

北极星指标：**预约履约率** = 已归还预约数 / 已审批预约数，衡量“预约 → 使用 → 归还”闭环是否真正完成。

核心指标体系：

| 指标 | 口径 | 目标 | 数据来源 |
|---|---|---|---|
| 预约创建成功率 | 创建成功数 / 创建尝试数 | >= 90% | 前端埋点 + 后端日志 |
| 审批时效 | 审批通过时间 - 提交时间，观察 P50 / P90 | P50 <= 24h | 预约表 |
| 库存准确率 | 1 - 库存不一致预约数 / 总预约数 | >= 99% | 库存日志 |
| 归还及时率 | 按时归还数 / 已审批数 | >= 90% | 预约表 |
| 冲突拦截率 | 被拦截冲突数 / 总提交数 | 建立基线 | 前端埋点 |
| 超期未还率 | 超期未还数 / 已审批数 | <= 5% | 预约表 |

## 2. 验收标准

验收覆盖以下核心场景：

| 场景 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| 创建预约 | 学生已登录、设备有库存 | 提交合法预约 | 状态 PENDING |
| 数量超库存 | 设备可用 5 件 | 提交 6 件 | 拒绝，提示当前可用库存不足 |
| 时间冲突 | 同设备同时间段已有预约 | 再次提交 | 拒绝，提示时间段已被占用 |
| 审批通过 | 管理员审批合法预约 | 点击通过 | APPROVED，库存扣减 |
| 审批驳回 | 管理员操作 | 点击驳回 | REJECTED，库存不变 |
| 确认归还 | APPROVED 且未重复归还 | 点击归还 | RETURNED，库存加回 |
| 权限隔离 | 普通用户登录 | 访问审批 / 用户管理 | 被拒绝 |
| 黑名单限制 | 用户已被标记失信 | 提交预约 | 拒绝并提示黑名单截止日期 |

## 3. 上线回收机制

建议在上线后增加以下对账与回收机制：

- 每日库存一致性对账：`available_qty + 未归还预约数量 = total_quantity`。
- 每周输出审批时效、归还及时率、超期未还率。
- 指标超过阈值时触发管理员预警，定位是需求规则、操作习惯还是系统缺陷。

## 4. 面试可讲

- 为什么库存扣减用原子更新而不是先查后扣：避免并发审批超卖。
- 为什么 PENDING 阶段不立即扣库存：未审批预约不应长期占用库存，避免影响其他用户。
- 为什么审批时再次校验：提交到审批之间数据可能变化，必须二次校验。
